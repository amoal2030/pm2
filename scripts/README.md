# دليل توليد صور الأصناف بالذكاء الاصطناعي (Gemini)
## مشروع منيوم أصناف (بروستد مشوار الفرسان)

هذا السكربت يتيح لك توليد صور طعام واقعية واحترافية لجميع أصناف المنيو الفعلية، وحفظها مباشرة كملفات صور ثابتة داخل المشروع (`public/menu-images/`) لتنشر مع الموقع على **GitHub Pages** دون الحاجة إلى خادم أو قاعدة بيانات.

---

### المتطلبات الأساسية
- تثبيت بايثون (Python 3.8 أو أحدث) على جهازك.
- مفتاح API من Google Gemini (`GEMINI_API_KEY`).

---

### طريقة التشغيل لمستخدمي Windows

#### الخطوة 1: فتح موجه الأوامر (Command Prompt أو PowerShell)
افتح المجلد الرئيسي للمشروع:
```cmd
cd path\to\your\project
```

#### الخطوة 2: تعيين مفتاح Gemini API
في **Command Prompt (CMD)**:
```cmd
set GEMINI_API_KEY=AIzaSy...مفتاحك_هنا
```
أو في **PowerShell**:
```powershell
$env:GEMINI_API_KEY="AIzaSy...مفتاحك_هنا"
```

#### الخطوة 3: اختبار توليد صورة لصنف واحد أولاً (صنف بروستد عادي 4 قطع)
```cmd
python scripts/generate_images.py --test
```
- سيقوم السكربت بتوليد صورة أول صنف وحفظها في `public/menu-images/br-1.png`.
- بعد انتهاء السكربت، افتح الموقع أو حدّث الصفحة وستشاهد الصورة الجديدة فوراً في بطاقة الصنف الأول وفي نافذة التفاصيل.

#### الخطوة 4: التحقق من حالة المنيو والتقدم
```cmd
python scripts/generate_images.py --status
```
سيعرض لك إحصائية بالأصناف المكتملة والمتبقية.

#### الخطوة 5: توليد بقية الأصناف على دفعات مريحة
لتوليد دفعة من 5 أصناف:
```cmd
python scripts/generate_images.py --batch-size 5
```
أو لتوليد 10 أصناف:
```cmd
python scripts/generate_images.py --batch-size 10
```
أو لتوليد كل الأصناف المتبقية دفعة واحدة:
```cmd
python scripts/generate_images.py --all
```

---

### مميزات السكربت:
1. **استئناف تلقائي**: يتجاوز الأصناف التي تم توليد صورها مسبقاً، ولا يعيد استهلاك الرصيد.
2. **بدون خادم**: الصور تحفظ كملفات `PNG` حقيقية وتُرفع مع الكود إلى GitHub Pages بـ `git push`.
3. **أمان تام**: لا يتم تخزين مفتاحك داخل الكود المصدري المنشور.
4. **تسمية موحدة**: تسمية كل صورة بمعرف الصنف (مثل `br-1.png`, `gr-2.png`, `pz-5.png`) لضمان عدم التداخل.
